This folder contains my first exercises in the *C programming language*.  
These exercises focus on the fundamental concepts and simple programs to start learning C.

+ 📝 Contents

- *01-display.c* → Simple output example (Hello World, printing messages)  
- *02-addition.c* → Adding two numbers  
- *03-input.c* → Reading input from the user  
- *04-converter.c* → Small unit converter (e.g., Celsius ↔ Fahrenheit)

+ 🎯 Goal

The purpose of this folder is to *practice the very first concepts of C* and get familiar with compiling and running programs.  
It serves as the foundation for more advanced exercises and projects later on.

+ 💡 Notes

- Each file is numbered to keep the exercises *in chronological order*.  
- Every program includes comments to explain the steps and logic.  

Keep practicing and building your foundation! 🚀
